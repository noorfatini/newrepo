## Example: Successful Response

`POST /api/tickets` (valid body) -> `201 Created`:

```json
{
  "id": "T004",
  "title": "VPN connection not working",
  "description": "User cannot connect to company VPN from home.",
  "category": "Network",
  "priority": "MEDIUM",
  "status": "OPEN",
  "createdBy": "siti@example.com",
  "createdAt": "2026-08-22"
}
```

## Example: Error Response

`GET /api/tickets/T999` (missing ticket) -> `404 Not Found`:

```json
{
  "errors": [],
  "message": "Ticket T999 was not found"
}
```

## Notes
Having every endpoint in one `.http` file makes it easy to re-run the whole set after any backend change, instead of re-testing each endpoint one at a time.
